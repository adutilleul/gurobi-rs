Controls Outer Approximation (OA) cut generation. Use 0 to disable these cuts, 1 for moderate cut generation, or 2 for aggressive cut generation. The default -1 value chooses automatically. This parameter is not overridden by the Cuts parameter.

Only affects MIQP, MIQCP, or MINLP models
